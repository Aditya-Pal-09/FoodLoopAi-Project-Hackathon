# FoodLoopAi-Project-Hackathon

🌱 FoodLoop AI

Turn surplus food into meals, before it becomes waste.

FoodLoop AI is an AI-powered food rescue platform that connects organizations with surplus food to community organizations that can redistribute it before it becomes waste.

Built as a Climate & Communities hackathon project, FoodLoop combines AI-assisted food analysis, deterministic rescue scoring, recipient matching, pickup tracking, and impact measurement into one simple workflow.

---

🚨 The Problem

Every day, large amounts of edible food are wasted by:

- 🍽️ Restaurants
- 🏫 College canteens
- 🏨 Hotels
- 🎉 Events
- 🏢 Institutions

At the same time, community kitchens, shelters, and NGOs may need food.

The problem is often coordination and timing.

FoodLoop AI helps create a simple bridge between surplus food and organizations that can potentially use it.

---

💡 The Solution

FoodLoop AI provides an end-to-end workflow:

Donor posts surplus food
↓
AI analyzes the listing
↓
Rescue Score identifies priority
↓
Best recipient is matched
↓
Recipient accepts donation
↓
Pickup is tracked
↓
Impact statistics are updated

---

✨ Key Features

🍱 Food Donation

Donors can create food listings with:

- Food name
- Quantity
- Estimated servings
- Food type
- Prepared time
- Available-until time
- Pickup location
- Notes
- Optional image

🤖 AI Food Analysis

FoodLoop AI analyzes donation information and provides:

- Food category
- Urgency
- Explanation
- Recommended action
- Potential concerns
- Suggested recipient type

«Responsible AI: FoodLoop AI provides organizational recommendations and does not certify food safety, freshness, or legal eligibility for redistribution.»

🏆 Rescue Score

Every listing receives a deterministic 0–100 Rescue Score based on:

Factor| Weight
Urgency| 40%
Time Remaining| 20%
Quantity / Servings| 30%
Listing Completeness| 10%

Priority levels:

- 🟢 80–100: High
- 🟡 50–79: Medium
- 🔵 0–49: Low

🤝 Recipient Matching

FoodLoop calculates a Match Score using:

- Distance — 30%
- Capacity — 30%
- Food compatibility — 25%
- Urgency — 15%

The system identifies the best available recipient and explains why it is recommended.

🚚 Pickup Tracking

Donations move through:

"Pending → Confirmed → Completed"

Completion updates the associated impact information.

📊 Impact Dashboard

Track:

- Meals rescued
- Estimated food diverted
- Successful pickups
- Active donors
- Active recipients
- Recent rescued food
- Impact trends

Environmental metrics are presented as estimates, not exact measurements.

- "pickups"

Row Level Security and server-side operations should be used to protect application data and secrets.

---

🔐 Responsible AI & Security

FoodLoop is designed with responsible AI principles:

- AI API keys are kept server-side.
- AI does not certify food safety.
- AI does not guarantee freshness.
- AI does not make legal food-distribution claims.
- Rescue Scores are deterministic rather than randomly generated by AI.
- Environmental impact values are explicitly marked as estimates.
- Database access should use appropriate Supabase RLS policies.

🚀 Getting Started

1. Clone the repository

git clone https://github.com/YOUR_USERNAME/foodloop-ai.git
cd foodloop-ai

2. Install dependencies

npm install

3. Configure environment variables

Create a ".env.local" file and add the required Supabase and AI configuration.

Example:

NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
AI_API_KEY=your_server_side_ai_key

«Never commit real API keys or secrets to GitHub.»

4. Run locally

npm run dev

Open:

http://localhost:3000
